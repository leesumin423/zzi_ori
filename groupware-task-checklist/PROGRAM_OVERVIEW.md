# 📋 그룹웨어 업무 체크리스트 자동화 (Groupware Task Checklist)

> 그룹웨어 메일함·전자결재함을 자동으로 읽고, 마감일이 언급된 항목을 추출해 **메모지 팝업**으로 띄워주는 RPA 도구입니다.  
> 매일 아침 7시 40분 자동 실행 → 오늘/이번주/차주 기한별로 정리된 업무 목록을 확인할 수 있습니다.

---

## 🎯 만든 목적

회사 그룹웨어(웹 기반)를 매일 직접 열어서 마감일을 수동으로 확인하는 번거로움을 없애기 위해 만들었습니다.

| 기존 방법 | 이 프로그램 |
|---|---|
| 매일 아침 그룹웨어 로그인 | 자동 실행 (Windows 작업 스케줄러) |
| 메일함 직접 스크롤하며 마감 확인 | 마감 표현 자동 추출 |
| 전자결재 완료함·참조함 별도 확인 | 메일함 + 전자결재 4개 함 동시 조회 |
| 머릿속으로 날짜 계산 | 지남 / 오늘 / 이번주 / 차주 자동 분류 |
| 완료 여부 기억 | 완료 체크 → 다음날 자동 제외 |

---

## 🏗️ 전체 동작 흐름

```
[Windows 작업 스케줄러 - 07:40 자동 실행]
          │
          ▼
  1. 로그인 세션 확인
     ├─ 세션 유효 → 재사용
     └─ 세션 없음/만료
           ├─ GW_ID/GW_PW 자동 로그인 시도
           └─ 실패 시 → 브라우저 창 열기 (수동 로그인 유도)
                 └─ 로그인 완료 감지 → 세션 저장 → 계속 진행
          │
          ▼
  2. 데이터 수집 (Playwright 헤드리스 크롤링)
     ├─ 메일함 (받은메일함)
     └─ 전자결재 (부서함-완료함, 부서함-참조/회람함, 개인함-완료함, 개인함-참조/회람함)
          │
          ▼
  3. 마감일 추출 (NLP-less 정규표현식 기반)
     ├─ "마감/까지/제출/회신" 키워드 문장 탐지
     └─ 날짜 표현 파싱 → 절대 날짜 변환
          │
          ▼
  4. 분류 및 필터링
     ├─ 이전 완료 체크 항목 제외
     └─ 기한별 분류: 지남 / 오늘 / 이번주 / 차주 / 월별
          │
          ▼
  5. 메모지 팝업 표시 (tkinter)
     └─ 완료 체크 → 저장 → 다음 실행 시 제외
```

## 📦 수집하는 자료

### 조회 대상

| 구분 | 화면 | `.env` 설정 키 |
|---|---|---|
| 메일함 | 받은메일함 | `GW_MAIL_LIST_URL` |
| 전자결재 | 부서함 완료함 | `GW_APPROVAL_DEPT_COMPLETED_URL` |
| 전자결재 | 부서함 참조/회람함 | `GW_APPROVAL_DEPT_REFERENCE_URL` |
| 전자결재 | 개인함 완료함 | `GW_APPROVAL_PERSONAL_COMPLETED_URL` |
| 전자결재 | 개인함 참조/회람함 | `GW_APPROVAL_PERSONAL_REFERENCE_URL` |

### 각 항목에서 추출하는 정보

```
Task (항목 하나)
  ├─ source       : "mail" 또는 "approval"
  ├─ folder       : 어느 함에서 왔는지 (예: "메일함", "부서함-완료함")
  ├─ title        : 메일 제목 또는 결재문서 제목
  ├─ sender       : 발신자 이름
  ├─ receiver     : 받는사람 (메일)
  ├─ doc_date     : 수신일 / 결재 상신일
  ├─ due_date     : 추출된 마감일
  ├─ matched_text : 마감일이 언급된 원문 문장
  ├─ raw_snippet  : 본문 앞 1,500자 (원문 보기용)
  └─ url          : 해당 화면 URL
```

### 조회 범위 설정 (`.env`)

```ini
MAIL_LOOKBACK_DAYS=14        # 최근 14일치 메일 조회
APPROVAL_LOOKBACK_DAYS=14    # 최근 14일치 결재 조회
MAIL_MAX_PAGES=5             # 메일함 최대 5페이지
APPROVAL_MAX_PAGES=3         # 결재함 최대 3페이지
```

## 🔍 마감일 추출 방식

### 1단계: 마감 키워드 문장 탐지

본문을 문장 단위로 쪼개고, 아래 키워드가 포함된 문장만 후보로 선택합니다.

```python
DEADLINE_KEYWORDS = [
    "까지", "마감", "제출", "회신", "바랍니다", "부탁드립니다",
    "완료해", "완료 부탁", "기한", "데드라인", "회신 요청",
    "제출 요청", "보고 바랍니다", "송부 바랍니다", "확인 바랍니다",
    "결재 요청", "영업일",
]
```

> **왜 이 방식?** 날짜만 보면 "작성일: 7/1" 같은 표현도 마감일로 오탐됩니다.  
> 마감 의미의 키워드가 있는 문장에서만 날짜를 찾아 오탐률을 크게 줄입니다.

### 2단계: 날짜 패턴 파싱

후보 문장에서 다양한 날짜 표현을 실제 `date` 객체로 변환합니다.

| 입력 표현 | 해석 방법 |
|---|---|
| `7월 15일`, `07/15`, `2026-07-15` | 절대 날짜 |
| `이번주 금요일`, `차주 월요일` | 메일 수신일(anchor_date) 기준 상대 계산 |
| `내일`, `모레` | anchor_date + 1일, +2일 |
| `다음주`, `금주` | anchor_date 기준 주 계산 |
| `N일 이내`, `N영업일` | anchor_date + N일 계산 |

### 3단계: 행 속성 우선 사용 (메일함)

그룹웨어 메일 목록의 체크박스 `<input>` 태그에는 이미 정확한 메타데이터가 들어있습니다.  
본문 텍스트 추측보다 훨씬 정확하므로 최우선으로 사용합니다.

```html
<!-- 그룹웨어 메일 행 HTML 예시 -->
<input type="checkbox"
  subject="[계약 건] 7월 18일까지 서류 제출 요청"
  sender="홍길동"
  receivedate="2026-07-15 0930"
/>
```

## 🗂️ 분류 기준

| 버킷 | 조건 | 표시 색상 |
|---|---|---|

| YYYY년 MM월 | 차주 이후 | 남색 |
| 날짜 미확인 | 날짜 파싱 실패 | 회색 |

## 🚫 자동 제외 필터

| 필터 | 설정 | 설명 |
|---|---|---|
| 제목/키워드 제외 | `MAIL_SUBJECT_EXCLUDE=전표승인요청서` | 특정 제목이 포함된 메일 제외 |
| 발신자 제외 | `SENDER_EXCLUDE=허다경,noreply@` | 관련 없는 발신자 제외 |
| 참조(Cc)만 걸린 메일 제외 | `MY_NAME=이수민` + `EXCLUDE_CC_ONLY=true` | 받는사람이 아닌 참조 메일 제외 |
| 이전 완료 체크 항목 | 자동 | 이전 실행에서 완료 처리한 항목 제외 |

## ⚙️ 로그인 처리 상세

세션 상태에 따라 3단계로 처리합니다.

```
1순위: .state/storage_state.json (저장된 쿠키 재사용)
    ↓ 실패 또는 없음
2순위: GW_ID + GW_PW 자동 로그인 시도
    ↓ 실패 (캡차, 2차인증, 비밀번호 변경 팝업 등)
3순위: 브라우저 창 직접 열기 → 사용자 수동 로그인
       → 로그인 완료 자동 감지 (최대 5분 대기)
       → 세션 저장 → 자동 크롤링 재개
```

> **장점**: 캡차, OTP, 비밀번호 변경 안내 같은 예외 상황도 사람이 직접 처리할 수 있어 안정적입니다.

## 🤖 (선택) AI 기안 검토 기능 (`review_drafts.py`)

메인 체크리스트 기능과 별개로, 전자결재 임시함에 저장된 기안 문서를 결재 올리기 전에 AI로 검토하는 기능입니다.

- **사용 모델**: Anthropic Claude (`claude-opus-4-8` 기본값)
- **검토 방식**: 기안 본문 + 첨부파일(PDF)을 Claude API로 전송 → 오탈자, 금액 불일치, 양식 오류 검토
- **주의**: 회사 내부 데이터가 외부 API로 전송됩니다. 사용 전 사내 데이터 정책을 확인하세요.

```ini
# .env 설정
GW_APPROVAL_TEMP_URL=...     # 임시함 URL
ANTHROPIC_API_KEY=sk-...     # Anthropic API 키
REVIEW_EFFORT=high           # 검토 강도 (low/medium/high/xhigh/max)
```

## ⚠️ 주의사항

- `.env` 파일에는 로그인 정보가 들어있습니다. **절대 git에 올리지 마세요.** (`.gitignore`에 등록되어 있습니다.)
- `.state/storage_state.json`도 로그인 쿠키가 담겨있습니다. 마찬가지로 git 제외 대상입니다.
- 그룹웨어 화면 구조가 변경되면 선택자 조정이 필요할 수 있습니다. `HEADED=true`로 설정하면 브라우저 창이 보이는 상태로 실행되어 디버깅에 유용합니다.
