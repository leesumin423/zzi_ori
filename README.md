# 🚀 (주)동양 자금팀 AI 업무 자동화 & 자금통합포털 (zzi_ori Treasury AI Portal)

> **프로젝트 개요**: 본 프로젝트는 (주)동양 자금팀의 핵심 자금 업무(주가·공시 모니터링, 차입금/만기 관리, 퇴직연금 운용, 월간 자금보고서 작성, 단기자금 판단 메일 발송, 그룹웨어 업무 체크리스트 등)를 독립 모듈로 개발하고, 단일 **자금통합포털(Flask 허브, 포트 9000)**로 일원화 구축하기 위한 AI 자금 업무 통합 솔루션입니다.

## 📚 4대 영역별 상세 기능 및 문서 체계 (MD Master Index)

### 1. 📈 주가 (Stock Status & Market Data) — Port 5000

- **담당 시스템**: 주가현황 대시보드 (`주가현황.html`, `dashboard.js`, `styles.css`, `server.py`)
- **실행 포트**: `http://10.62.15.197:5000` (Flask)
- **주요 기능**:
  - 계열사(동양, 유진기업 등) 및 경쟁 시멘트사 실시간 주가, 시가총액, 52주 최고/최저 조회.
  - KOSPI / KOSDAQ 지수, USD/KRW 환율, 테마별 시세 동향 자동 집계.
  - 외국인/기관 수급 동향 자동 코멘트 생성 및 KRX/네이버 금융 데이터 파싱.

#### 📄 상세 문서
- [`1-1_데이터_출처.md`](1-1_데이터_출처.md) : **[필수 참고]** 주가/지수/환율/수급/자본금 등 화면 각 숫자의 정확한 API 엔드포인트 및 네이버 금융/KRX 연동 함수 명세서.

### 2. 📋 공시모니터링 (Disclosure Monitoring System) — Port 5000

- **담당 시스템**: DART 공시 통합 감시 시스템 (`server.py`, `danpan_mail.py`, `danpan_tracking_db.py`)
- **실행 포트**: `http://10.62.15.197:5000` (Flask / DART Open API)
- **주요 기능**:
  - **단판공시**: "단일판매·공급계약체결" 현장별 계약 금액 스크랩, 사업연도 롤오버(4/1), 사전검증 계산기 및 변동이력 자동 메일링.
  - **지분공시**: 임원/주요주주 소유상황보고 및 대량보유 5% Rule 자동 점검 (3필드 검증).
  - **공정위 공시**: 특수관계인 출자·채권매도·상품용역거래 3종 자동 집계 및 20% 계열사 27개사 점검.

#### 📄 상세 문서
- [`2-1_단판공시_모니터링.md`](2-1_단판공시_모니터링.md) : 단판공시(단일판매공급계약) 스크랩, 롤오버 계산기, 메일링 로직 및 이력 DB 명세.
- [`2-2_지분공시_모니터링.md`](2-2_지분공시_모니터링.md) : 지분공시·5% Rule 3필드 점검, 대량보유상황보고서 체크리스트 및 가이드.

### 3. 💰 자금관리 (Treasury & Loan Management) — Port 8501 / Port 9000

- **담당 시스템**: 차입금관리 (`app.py`, Streamlit) + 통합포털 허브 (`app.py`, Flask Port 9000) + 그룹웨어 체크리스트
- **실행 포트**: 차입금관리 `http://10.62.15.197:8501` / 통합포털 `http://10.62.15.197:9000`
- **주요 기능**:
  - **차입금 관리**: 단/장기 차입 잔액, 금융기관별 가중평균 차입금리(%p) 및 연간 이자 비용 자동 계산.
  - **월간 자금 보고**: 월간 자금 유입/유출 수지, 운용자산 잔액 DB화 (`monthly_report_db.py`) 및 엑셀/PDF 보고서 서식화 (`report_shared.py`).
  - **그룹웨어 체크리스트**: 메일/전자결재함 헤드리스 크롤링(Playwright)으로 마감일 업무 자동 파싱.

#### 📄 상세 문서
- [`3-1_자금통합포털_계획.md`](3-1_자금통합포털_계획.md) : 허브 통합포털(Port 9000) 현황, RBAC 접근 권한 및 전체 개발 이력.
- [`3-2. groupware-task-checklist/README.md`](groupware-task-checklist/README.md) : 그룹웨어 결재/메일 크롤링 및 업무 마감 체크리스트 가이드.

### 4. 🧓 퇴직연금 (Retirement Pension System) — Port 8000

- **담당 시스템**: 퇴직연금 통합관리 시스템 (`run_dashboard.py`, `pension_server.py`, `app.js`, `style.css`)
- **실행 포트**: `http://10.62.15.197:8000` (Flask / SQLite)
- **주요 기능**:
  - 10여 개 금융기관(농협, 기업은행, 산업은행 등) 퇴직연금 엑셀 파싱 (`parse_data.py`).
  - 원리금보장형(GIC, ELB/DLB) 및 실적배당형(펀드) 가중평균 수익률(%p) 및 연간 이자수익 산출.
  - 잔존 만기 구간별(3개월/6개월/1년) 자산 금액/평균 금리 시각화 및 전년말 대비 YoY(▲/▼) 이상치 감지.

- [`4-2_퇴직연금_대시보드.md`](퇴직연금통합관리시스템/4-2_퇴직연금_대시보드.md) : 퇴직연금 대시보드 파일 구조, SQLite DB 관리 및 파서 설치 안내.

## 🔐 보안 및 배포 전 체크리스트

1. **저장소 Private 설정**: API 키 및 사내 IP/URL 노출 방지를 위해 저장소 Private 상태 유지.
2. **비밀키 관리**: `.dart_api_key`, `.krx_api_key`, `.env` 파일은 절대 Git commit 대상에 포함하지 않음 (`.gitignore` 등록 확인).
3. **포트 중복 점검**: 사내 서버(10.62.15.197)에서 5000, 8000, 8501, 9000 포트 방화벽 열림 상태 확인.
