## 공시 → 「자금 공시 영역 업데이트 세션」

### 공정위 공시 정보 조회 API (2026-08-31, 보관 처리)
- 목표: 기업집단포털에 매년 제출하는 자료(지정, 주식, 채무, 공시점검, 지배구조, 내부거래)가 해마다 비슷하므로, 이미 있는 자료를 끌어와 작성할 때 참고할 수 있게 하는 것입니다.
- API: `apis.data.go.kr/1130000/appnGroupSttusList` (공정위 지정기업집단현황 계열). 공정위가 공개한 결과물(집단명, 동일인, 계열회사수, 자산총액 등)일 가능성이 큽니다. 6개 카테고리를 한 API로 모두 가져오지는 못하고, 카테고리별 API를 각각 활용신청해야 할 것으로 보입니다.
- 현재 상태: 호출 결과가 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`(코드 30)입니다. 해당 API의 활용신청이 아직 승인되지 않았을 가능성이 큽니다.
- **다음 단계**:
  1. data.go.kr 마이페이지 → 오픈API → 개발계정에서 승인 상태를 확인합니다.
  2. 승인되면 정상 응답 예제를 확보합니다.
  3. 연동 모듈을 설계합니다. 기존 `server.py`의 DART 연동 패턴과 `통합포털/ftc_disclosure_mail.py`를 참고합니다.
- 서비스키는 대화에 있던 값을 사용합니다. 이 문서에는 기록하지 않았습니다.
