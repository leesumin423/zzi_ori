# 내 자산 대시보드

급여 · 미국주식 · 국내 ETF(연금저축/IRP/ISA) · 배당 · 복지기금 대출을 한 화면에서 보는 개인용 도구입니다.
수기로 관리하는 엑셀 3개를 그대로 읽고, 나머지(환율·현재가·평가액·배당·연도별 증감)는 자동으로 계산합니다.

## 쓰는 법 (Windows)

1. `자산대시보드/data/` 폴더에 엑셀 3개를 넣습니다. 파일 이름은 상관없고 내용으로 자동 구분합니다.
   - 급여 엑셀 (`○○년 소급분` 행이 있는 파일)
   - 대출 엑셀 (`복지기금` 시트가 있는 파일)
   - 미국포트폴리오 엑셀 (암호 걸린 파일: `미국주식_…`, `YY년_매수일지`, `배당시트(YY)` 시트)
2. `자산대시보드_실행하기.bat` 더블클릭 → 비밀번호 입력 → 브라우저가 `http://127.0.0.1:8765` 로 열립니다.
3. 엑셀을 고친 뒤에는 실행기를 다시 켜면 됩니다.

맥/리눅스: `python3 asset_dashboard.py` (서버) 또는 `python3 asset_dashboard.py --static output/대시보드.html` (HTML 한 장으로 저장)

## 자동으로 계산되는 것

| 항목 | 출처 |
|---|---|
| 연말·분기말·오늘 환율 | 서울외국환중개 USD 매매기준율 (휴일이면 직전 영업일) |
| 실시간 환율 | 네이버 (하나은행 고시) — 없으면 당일 매매기준율 |
| 실시간 현재가 | 네이버증권 (국내 6자리 코드, 미국 티커) — 30초마다 갱신 |
| 연말 종가 · 배당 이력 · 분할/병합 | Yahoo Finance (분할·병합은 시트 수량과 맞춰 자동 보정) |
| 평가액 | 보유수량 × 종가 (미국은 × 환율) |
| 예상 연배당 | 보유수량 × 최근 12개월 주당배당금 (세후: 미국 15%, 국내 15.4% 가정) |
| 연도별 자산 증식 | 연말 스냅샷 비교 → 내 돈 납입 / 주가 효과 / 환율 효과 / 대출 증감 |
| 종목별 연간 수익 | 연말 평가 − 전년말 평가 − 순매수 + 매도 실현손익 |

## 증권사(계좌)별 보유 관리

- 미국: 최신 분기 시트의 `증권사` 열 + `분산종목` 합계와의 차이를 **계좌 미지정** 행으로 표시
- 국내: 최신 `YY년_매수일지`의 `투자처 별 잔고`
- 화면의 **보유 종목** 표에서 계좌·수량·평단을 바로 고치거나, 아래 폼에서 티커로 조회해 종목을 추가하거나, 삭제할 수 있습니다.
  수정 내용은 `data/내종목_수정.json`에 저장되고 엑셀 원본은 건드리지 않습니다. `수정 초기화`로 엑셀 기준으로 돌아갑니다.
- 종목명 → 티커 연결은 `data/종목코드.json`(`{"종목명": "티커"}`)에서 읽습니다. 보유 목록이 공개 저장소에 올라가지 않도록
  코드에는 넣지 않았습니다. 화면 표의 '티커' 칸에서 고치면 이 파일에 자동 저장됩니다.

## 보안

- 비밀번호는 실행할 때 입력받거나 환경변수 `ASSET_XLSX_PASSWORD`로만 받고, 어떤 파일에도 저장하지 않습니다.
- 암호 해제는 메모리에서만 합니다(해제된 엑셀을 디스크에 쓰지 않음).
- 서버는 내 PC(127.0.0.1)에서만 열립니다.
- `data/`, `cache/`, `output/` 폴더는 `.gitignore`에 등록돼 커밋되지 않습니다.
