# (주)동양 퇴직연금 보고 시스템

(주)동양의 퇴직연금(DB형) 운용 현황을 결산기(연말/분기/반기/월별)마다 정리하고, 운용 수익률과 상품 운용 적정성을 평가하기 위한 엑셀 템플릿 세트.

## 프로젝트 목표 (4단계)

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 퇴직연금 현황 템플릿 (연말/분기/반기/월별 공용, 재사용 가능한 서식) | ✅ 완료 |
| 2 | 퇴직연금 운용 수익률 현황 (불입일 ~ 운용기간까지 실제 수익 계산) | ⏳ 예정 |
| 3 | 월별 현황 업데이트를 기반으로 2번(수익률)을 산출하는 로직 | ⏳ 예정 |
| 4 | 운용평가 보고서 (상품이 적절히 운용되었는지 평가) | ⏳ 예정 |

## 배경

기존에는 결산기마다 별도 파일로 퇴직연금 현황을 정리해왔는데(2020~2026년 스냅샷 다수 존재), 연도마다 표 양식이 조금씩 달라 자동 집계나 시계열 비교가 어려웠음. 이 프로젝트는 하나의 표준 서식으로 통일하고, 향후 수익률 계산 및 운용평가까지 이어지는 기반을 만드는 것이 목적.

## 1단계 산출물: 현황 마스터 템플릿

`템플릿/퇴직연금_현황_마스터템플릿.xlsx`

**시트 구성**
- **입력안내** — 사용법, 색상 규칙(파란 글씨=직접입력 / 검은 글씨=자동계산), 최초가입일 추정 로직 설명
- **기본사항** — 퇴직급여추계액·추가불입액·퇴직연금평가액·적립비율 등 기준일 단위 지표
- **1.퇴직연금현황** — 메인 테이블. 상품별 구분/연금사업자/상품명/금리/최초가입일/만기일/평가금액을 입력하면 지점 소계·예상연이자·만기구간 분포·가중평균금리·1금융·2금융 비중이 자동 계산됨
- **스냅샷이력** — 매 기준일의 요약 수치(총 운용금액, 가중평균금리, 만기 비중 등)를 자동 계산해두는 시트. 매 기준일마다 이 값을 누적 이력표에 이어붙이면 2·3단계(수익률 계산)의 원재료가 됨

**핵심 설계 — 최초가입일 추정**

기존 파일들은 같은 은행에서 상품이 롤오버될 때 최초가입일이 그룹의 첫 행에만 기재되고 이후 회차에는 비어 있었음(정확한 불입일 원장 없음). 이 템플릿은 상품명에 포함된 계약기간("1년"/"2년"/"3년"/"5년")을 자동 인식해 `만기일 − 계약기간`으로 해당 회차의 운용개시일을 추정한다. 실제 원장 값이 있으면 그 값이 우선 적용되고, 추정된 값은 비고란에 "추정치"로 표시된다. 만기·계약기간 정보 자체가 없는 상품(펀드, 현금성자산 등)은 "확인 필요"로 별도 표시된다.

## 향후 개발 계획 (2·3·4단계)

- **운용 수익률 현황**: 1단계 템플릿의 최초가입일(원장/추정)과 평가금액을 기초로, 상품별 경과기간 × 금리로 발생주의 수익을 추정. 정확한 개별 불입일 원장이 없으므로 완전한 실측이 아닌 추정치 기반이라는 한계를 명시할 것.
- **월별 업데이트 → 수익률 산출**: 매월 1단계 템플릿을 갱신하면서 스냅샷이력 시트에 요약치를 누적, 잔액 변동과 경과일수를 비교해 기간별 실현 수익을 근사 계산하는 로직 추가.
- **운용평가 보고서**: 가입 시점 금리가 그 시점 시장/대체 상품 금리 대비 적절했는지, 계열사 상품 편입 한도(5%) 등 규정 준수 여부, 기관/상품 분산도를 종합해 평가하는 보고서 서식.
