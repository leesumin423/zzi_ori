# 4-2. 퇴직연금 대시보드 및 데이터베이스 안내 (퇴직연금 / Port 8000)

> **프로젝트 개요**: 본 프로젝트는 (주)동양 자금팀의 핵심 자금 업무(퇴직연금 운용, 차입금 및 만기 관리, 월간 자금보고서 작성, 단기자금 판단 메일 등)를 통합 파이프라인과 웹 대시보드로 자동화하고, 단일 **자금통합포털(`zzi_ori`)**로 이원화된 시스템을 일원화 구축하기 위한 AI 자금 업무 자동화 솔루션입니다.

---

## 📌 깃허브 리포지토리 연동 및 개발 방향 (`zzi_ori`)

- **메인 프로젝트 리포지토리**: [https://github.com/leesumin423/zzi_ori](https://github.com/leesumin423/zzi_ori)
- **AI 리포지토리**: [https://github.com/leesumin423/-AI-](https://github.com/leesumin423/-AI-)
- **핵심 목표**:
  1. 각 담당자 PC의 개별 엑셀 파일로 파편화되어 관리되던 자금 데이터(퇴직연금 현황, 차입금 내역, 월간 보고서)를 자동 파싱 및 DB 구조화.
  2. 금융기관별 실시간 금리, 잔액, 만기 도래 현황, 가중평균 수익률 및 차입 이자 비용을 직관적인 대시보드로 시각화.
  3. 로컬 샌드박스 환경(Flask/Streamlit/Python)에서 검증된 3개 파트를 **통합 AI 자금포털(React + Vite + Supabase)**로 단계적 마이그레이션.

### 1. 🏦 퇴직연금 통합 관리 시스템 (Retirement Pension Management)
- **주요 기능**:
  - **다기관 엑셀 파싱 파이프라인**: 농협, 산업은행, 우리은행, 기업은행 등 10여개 금융기관의 퇴직연금 운용 엑셀 양식을 `parse_data.py`로 수집 및 통합 스냅샷 JSON(`data.json`) 빌드.
  - **수익률 & 이자 계산 Engine**: 원리금보장형(GIC, ELB/DLB, 정기예금)과 실적배당형(펀드)의 가중평균 수익률(%p) 및 연간 예상 이자 수령액 자동 산출.
  - **만기 구간 분석 & Drill-down**: 잔존 만기 구간별(3개월/6개월/1년) 자산 금액 및 구간 평균 금리 혼합 시각화, 당해연도 만기 상품 원클릭 추출.
  - **데이터 정합성 및 금리 이상치 자동 검증**: 동일 기관 + 동일 상품 + 동일 만기 상품의 전년 대비 금리 변동(이상치) 자동 탐지(`findRateAnomalies`).
  - **전년말 대비 YoY 비교 모달**: 가중평균 수익률 및 예상 이자 KPI 카드 클릭 시 기관별/상품유형별 이자수익 증감(▲/▼) 상세 분석 제공.

---

### 2. 💳 차입금 관리 시스템 (Borrowing & Loan Management)
- **주요 기능**:
  - **차입금 포트폴리오 모니터링**: 단기차입금, 장기차입금, 시설자금대출 등 금융기관별 차입 잔액 및 차입 조건 일원화 관리.
  - **가중평균 차입금리 & 이자 비용 산출**: 전체 차입 자산의 가중평균 차입금리(%p) 계산 및 연간 발생 이자 비용 추산.
  - **1년 이내 만기도래 상환계획표**: 만기도래 차입금의 연장/상환 상태(상환여부, 비고)를 로컬 DB와 연동하여 관리하고, 월별 리파이낸싱 일정 추적.
  - **그룹 차입 및 관계사 차입 관리**: 계열사/관계사 간 차입 및 대여금 내역(`group_loan.py`, `group_loan_db.py`) 별도 관리 및 이무 조건 추적.
  - **시장 금리 및 신용등급 연동**: 한국은행 기준금리 API, 회사채/CP 신용등급 추이(`credit_ratings.json`) 모니터링.

---

### 3. 📊 월간 자금 보고서 자동화 파트 (Monthly Treasury Report System)
- **주요 기능**:
  - **월간 자금 수지 집계**: 월별 자금 유입/유출, 운용자산 잔액, 차입금 잔액 및 순차입금 추이 자동 정리 (`monthly_report_db.py`).
  - **보고서 서식 자동 생성**: 경영진 보고용 표준 월간 자금 보고서를 엑셀 및 PDF 서식으로 자동 파싱 및 템플릿 출력 (`report_shared.py`).
  - **단기자금 판단(단판) 메일 자동화**: 일별/주별 단기자금 운용 상황 및 시중 금리동향을 정리하여 관련 부서로 자동 발송하는 메일러 모듈 연동 (`danpan_mail.py`).

## 🛠️ 기술 스택 (Technology Stack)

- **Backend & Data Processing**: Python 3.9+, Flask, Streamlit, `openpyxl`, `pandas`, SQLite/JSON DB
- **Frontend**: HTML5, Vanilla CSS (Glassmorphism), JavaScript (ES6), Chart.js v4, Plotly
- **Database (향후 포털)**: Supabase PostgreSQL (Row Level Security 적용)
- **Deployment**: Local Server (`run_dashboard.py`), Batch Script (`.bat`), Git & GitHub
