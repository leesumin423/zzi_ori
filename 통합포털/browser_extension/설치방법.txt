통합포털 - 기안 문서 전송 확장 설치 방법 (크롬/엣지 공용)

1. 주소창에 chrome://extensions (엣지는 edge://extensions) 입력해서 이동
2. 오른쪽 위 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭
4. 이 폴더(browser_extension)를 선택

설치되면 브라우저 툴바에 아이콘이 생깁니다. 사용법:
1. 그룹웨어에서 검토하고 싶은 기안 문서 화면을 엽니다(로그인된 상태)
2. 확장 아이콘 클릭 → "지금 보는 문서 통합포털로 보내기" 버튼 클릭
3. 새 탭이 열리며 통합포털 "전자문서 결재 check" 화면에 본문이 자동으로 채워집니다
4. 내용 확인 후 "검토 시작" 버튼을 눌러 AI 검수를 실행하세요

* 통합포털 주소가 10.62.15.197:9000이 아니라면, 확장 팝업의 "통합포털 주소 설정"에서 바꿔주세요.
* 이 확장은 통합포털 로그인 세션(쿠키)이 필요합니다 — 먼저 이 브라우저로 통합포털에 로그인해두세요.
* 첨부파일까지 자동으로 가져오진 않습니다(본문만) — 표ㆍ그림은 화면 캡처해서 검토 화면에 직접 첨부해주세요.
